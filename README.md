# AR Panorama Viewer

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

An A-Frame (WebVR) based panorama viewer that can display panoramic images in an AR-like cylindrical view.

## Demo
- https://code4fukui.github.io/ar-panorama-viewer/
- https://code4fukui.github.io/ar-panorama-viewer/?src=panorama-tojinbo-flip.jpg&tlen=200&h=3&r=3
- https://code4fukui.github.io/ar-panorama-viewer/v2.html
- https://code4fukui.github.io/ar-panorama-viewer/v2.html?src=panorama-tojinbo-flip.jpg

## Features
- Displays panoramic images in a cylindrical view
- Supports various options to customize the display
- Provides a simple and easy-to-use interface

## Usage
The project can be used by opening the `index.html` or `v2.html` files in a web browser. Various options can be passed as URL parameters to customize the display.
